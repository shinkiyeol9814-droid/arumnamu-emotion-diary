# 🌳 아름나무반 감정일기

어린이집 **아름나무반** 친구들(약 23명)이 노트북 한 대로 돌아가며
오늘의 감정을 고르고, 왜 그런 기분이었는지 적는 감정일기 앱입니다.
감정 그림과 앱 아이콘은 모두 아이가 직접 그린 그림입니다.

## 화면 흐름
1. **누가 일기를 쓸까요?** — 내 이름을 누릅니다. (오늘 쓴 친구는 ✔ 와 고른 감정 그림이 보여요)
2. **오늘의 감정을 골라보세요** — 30가지 감정 그림 중 하나를 고릅니다.
3. **감정일기** — 왜 그런 기분이었는지 쓰고, 오늘 날씨를 고른 뒤 "다 썼어요!"
4. **🌳 모아보기** — 날짜별로 반 친구 전체의 감정과 이유를 한눈에 봅니다. 감정별 인원도 나와요.
   친구 카드를 누르면 그 친구의 지난 기록을 모두 볼 수 있어요. 🖨️ 인쇄도 됩니다.
5. **🔒 선생님** — 친구 이름 바꾸기, 백업/불러오기, 엑셀(CSV) 내보내기, 기록 지우기. (처음 비밀번호 `1234`, 꼭 바꿔 주세요)

## 노트북에서 실행하기
1. GitHub에서 **Code → Download ZIP** 으로 받아 압축을 풉니다. (또는 `git clone`)
2. `src` 폴더의 **`index.html`** 을 크롬(Chrome) 또는 엣지(Edge)로 엽니다.
3. 자주 쓰도록 바탕화면에 바로가기를 만들거나, 브라우저 즐겨찾기에 추가해 두세요.
4. 처음 한 번 **🔒 선생님 → 친구 이름** 에서 반 친구 이름(또는 별명)을 한 줄에 하나씩 적고 저장합니다.

> 인터넷이 없어도 동작합니다. (글씨체만 기본 글꼴로 바뀌어요)

## 기록은 어디에 저장되나요?
- 기록은 **그 노트북의 그 브라우저 안(localStorage)** 에만 저장되고, 인터넷으로 보내지지 않습니다.
- 그래서 **항상 같은 노트북, 같은 브라우저, 같은 위치의 `index.html`** 로 열어야 기록이 이어집니다.
  (폴더를 옮기거나 다른 브라우저로 열면 빈 일기장으로 보입니다)
- 브라우저의 "인터넷 사용 기록 삭제(쿠키 및 사이트 데이터)" 를 하면 기록이 지워질 수 있으니
  **선생님 → 💾 백업 파일 받기** 로 가끔 백업해 주세요. 백업 파일은 GitHub에 올리지 마세요.

## 개발용
- 로컬 미리보기: `python -m http.server 8765 -d src` 후 http://localhost:8765
- `tools/crop_emotions.py`: 원본 그림(`src/img/original-chart.webp`)에서 감정 그림 30개와 아이콘을 잘라 냅니다.
