# 🌳 아름나무반 감정일기

어린이집 **아름나무반** 친구들이 노트북 한 대로 돌아가며
오늘의 감정을 고르고, 왜 그런 기분이었는지 적는 감정일기 앱입니다.
감정 그림과 앱 아이콘은 모두 아이가 직접 그린 그림입니다.

👉 **앱 주소: https://shinkiyeol9814-droid.github.io/arumnamu-emotion-diary/**
👉 **처음 설정: [SETUP.md](SETUP.md)**

## 화면 흐름
1. **누가 일기를 쓸까요?**: 내 이름을 누릅니다. 오늘 쓴 친구는 ✔ 표시와 함께 고른 감정 그림이 보입니다.
2. **오늘의 감정을 골라보세요**: 30가지 감정 그림 중 하나를 고릅니다.
3. **감정일기**: 왜 그런 기분이었는지 쓰고, 날씨를 고른 뒤 "다 썼어요!"를 누릅니다.
4. **🌳 모아보기**: 달력에서 날짜를 누르면 그날 반 전체의 감정과 이유, 감정별 인원이 나옵니다.
   친구 카드를 누르면 그 친구의 지난 기록이 모두 나옵니다.

## 구조
```
노트북 브라우저 ──▶ GitHub Pages (src/, push 하면 자동 배포)
        │
        └─ 저장/불러오기 ──▶ 구글 앱스 스크립트 (apps-script/Code.gs) ──▶ 구글 시트
                              반 비밀번호(CLASS_KEY)가 맞아야만 동작
```
- 아이들 **이름과 일기는 비공개 구글 시트에만** 저장됩니다. 이 저장소에는 들어 있지 않습니다.
- 인터넷이 끊기면 노트북에 잠시 보관했다가, 다시 연결되면 자동으로 올립니다.

## 개발
```bash
python tools/dev_server.py
```
http://localhost:8765 에서 열립니다. 테스트용 반 비밀번호는 `0000`이고, 명단은 가짜 이름 "친구 1~23"입니다.
구글 시트 대신 `tools/dev-db.json`을 씁니다.

- `src/`: 웹 앱(HTML, CSS, JS). `src/config.js`에 앱스 스크립트 주소를 넣습니다.
- `apps-script/Code.gs`: 구글 시트 저장소 코드
- `tools/crop_emotions.py`: 원본 그림에서 감정 그림 30개와 아이콘을 잘라 냅니다.
- `private/`: 실제 명단처럼 올리면 안 되는 파일. `.gitignore`로 제외되어 있습니다.
